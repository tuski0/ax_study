<summary style="font-size: 30px;">조건문 </summary>

- 판별식에 따라서 참이면 참에 실행되는 코드를 정의하고
거짓이면 거짓 조건에 실행되는 코드를 정의할 수 있는 문장
- 판별식 : 비교 연산자, 논리 연산자, 값

1. 단일 조건문
    ```python
    if 판별식 :
        판별식이 참일 때 실행되는 코드
    ```

2. if - else 조건문
	```python
    
    if 판별식 : 
    	참일 때 실행되는 코드
    else :
		거짓일 때 실해되는 코드
        
    ```

3. if - elif - else 조건문
	- elif는 여러번 사용 가능.
    ```python
    if 판별식 :
        참일 떄 실행되는 코드
    elif 판별식 :
        if는 거짓이고 elif는 참일때 실행되는 코드
    else :
        if, elif가 모두 거짓일때 실행되는 코드          
    ```
  
4. 중첩 조건문과 논리 연산자 결합

    ```python
    
    if num >= 10:
        if num < 100:
            print(f"{num}은 10 이상 100 미만")
    
    if num >= 10 and num < 100:
        print(f"{num}은 10 이상 100 미만")
        
    ```

1. for문
- i : 순서를 의미하는 index, 관례로 사용함, i, j, k, l 순서대로
- range(반복횟수) : 0 ~ 반복횟수
- range(시작, 종료) : 시작 이상 ~ 종료 미만
- range(시작, 종료, 증감) : 시작 이상 종료 미만 증감단위 range(0, 10, 2) → 0, 2, 4, 6, 8
- nums = [ *range(1, 101) ] → nums 리스트에 1부터 100까지 삽입

  ```python

  for i in range(반복횟수) :
  	# 반복 수행되는 코드
  ```
  
  ```python
  # 반복 횟수를 사용하지 않는 경우
  # 변수 자리에 _로 변수를 사용하지 않고 반복만 사용할 때
  for _ in range(10): 
  	print("반복") 
  ```
  
  ``` python
  fruits = ['사과', '포도', '수박', '배', '오렌지', '망고', '멜론']
  
  # for i in range(7) : 0 ~ 7 
  # for i in range(2, 7): # 2 ~ 7
  for i in range(0, 7, 2): # 0 ~ 7, 2씩 증가함 
  	print(fruits[i])
  ```
  
  ### 반복가능한 요소(iterable)의 반복
  ```python
  for i in ( list, tuple, set ) :
  	print(i)
    
  for i in dict.keys(), values() :
  	print(i)
    
  for key, value in dict.items() :
  	print(f"{key} - {value})
  
  for _, value in user.items() :
  	print(f'{value}')
  ```

3. 반복문의 중간 제어: break와 continue
- continue : 현재 반복을 중단하고 새로운 반복을 시작 (건너뛰기)
- break : 반복 중단
    ```python
    for _ in range(10) :
        num = int(input())

        if num == 99 :
            print('종료')
            break

        print(f'입력한 숫자 : {num}')
    ```

4. 이중 반복문과 시퀀스 중첩 순회
    <p style="font-size: 25px;">구구단</p>

    ```
    첫번째 반복은 단(2~8), 8회 반복
    각 단마다 1~9를 곱하는 반복
    ```

    ```python
    for i in range(2, 10) : # 단
        print('-' * 5, i, "단" , '-'*5)
        for j in range(1, 10) : # 곱하는 수
            print(f'{i} * {j} = {i*j}')
        
    ```
